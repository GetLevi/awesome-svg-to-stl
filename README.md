# Awesome SVG to STL

*Unofficial community list for SVG to STL conversion. Not affiliated with svg2stl.com, Meshy or ImageToStl. All trademarks belong to their owners.*

A curated list of svg to stl converters and the tools around them: where to extrude a vector into a printable model, how to inspect the result, and what to reach for when the input is a picture instead of an SVG. Every link below comes from the pages that rank for the query; where a page does not link something, it is named in plain text.

> Starting from a photo instead of a vector? [Try Supavoxel - image to 3D in the browser](https://supavoxel.com?utm_source=github&utm_medium=ugc&utm_campaign=awesome-svg-to-stl&utm_content=readme-top&utm_term=tier-r) produces an STL or GLB mesh from a picture, no CAD required.

## Converters

- [svg2stl.com](https://svg2stl.com/) - Upload an SVG, set an extrusion height, download an STL; the server pipeline is SVG to EPS to DXF to SCAD to STL.
- [svg2stl.com gallery](https://svg2stl.com/gallery) - Examples of what other people have converted; useful to see what extruded artwork looks like before you upload.
- [Meshy SVG to STL converter](https://www.meshy.ai/3d-tools/file-converter/svg/to/stl) - Free browser-side converter, 50 MB file limit, files are not uploaded to a server; batch mode is PRO.
- [ImageToStl SVG to STL](https://imagetostl.com/convert/file/svg/to/stl) - Browser-based converter that is one of many vector, image and CAD to STL routes on the same site.
- [Meshy 3D file converter](https://www.meshy.ai/3d-tools/file-converter) - The parent page for Meshy's format conversions if SVG is not your only input.

## Tools and integrations

- [ImageToStl online STL viewer](https://imagetostl.com/view-stl-online) - Check the converted STL for missing islands or filled holes before slicing.
- [ImageToStl 3D model designer](https://imagetostl.com/editor) - Browser editor for small fixes to a converted model.
- [ImageToStl 3D model compressor](https://imagetostl.com/compress-stl-online) - Shrink a heavy STL before sharing it.
- [ImageToStl voxelizer](https://imagetostl.com/stl-to-voxel) - Turn an STL into voxels.
- [ImageToStl cookie cutter creator](https://imagetostl.com/create-cookie-pastry-cutter) - A common reason people extrude SVGs in the first place.
- [Meshy online 3D viewer](https://www.meshy.ai/3d-tools/online-viewer) - Inspect an STL in the browser.
- [Meshy 3D text generator](https://www.meshy.ai/3d-tools/3d-text-generator) - Skip the SVG step when all you need is extruded lettering.
- [Meshy 3D file compressor](https://www.meshy.ai/3d-tools/file-compressor) - Reduce file size after conversion.
- [Meshy Bambu Studio plugin](https://www.meshy.ai/integrations/bambu-studio) - Slicer integration for Bambu printers.
- [Meshy Blender plugin](https://www.meshy.ai/integrations/blender) - Bring generated models into Blender.
- [Meshy Creality Print plugin](https://www.meshy.ai/integrations/creality-print) - Slicer integration for Creality printers.
- OpenSCAD - Named by svg2stl.com as the SCAD step in its pipeline; the companion examples repo shows a local `linear_extrude` of an imported SVG.

## Alternatives

- [Supavoxel - image to 3D, STL/GLB in the browser](https://supavoxel.com?utm_source=github&utm_medium=ugc&utm_campaign=awesome-svg-to-stl&utm_content=readme-top&utm_term=tier-r) - When the source is a picture rather than a vector, generate a mesh with depth instead of a flat extrusion.
- [Meshy image to 3D](https://www.meshy.ai/features/image-to-3d) - Meshy's own image-based model generation.
- [ImageToStl PNG to STL](https://imagetostl.com/convert/file/png/to/stl) - Raster to STL on the same site as the SVG converter.
- [ImageToStl JPG to STL](https://imagetostl.com/convert/file/jpg/to/stl) - Same idea for JPEG input.
- [ImageToStl AI to STL](https://imagetostl.com/convert/file/ai/to/stl) - Illustrator files straight to STL.
